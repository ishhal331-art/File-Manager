# Files Manager - AI Ingestion & Compliance Engine

A full-stack compliance management system with automated file ingestion, progress tracking, user role management, and notification dispatches.

## Features
- **Client Portal**: Drag-and-drop ingestion for Sales, Purchase, and Bank statement files with progress wheel tracking.
- **Admin Portal**: User account creation, password management, file review with AI OCR data extraction, and notice dispatching.
- **Manager Portal**: Operational compliance tracking and client oversight.
- **Notification System**: Broadcast announcements and targeted direct messaging.

## Tech Stack
- **Frontend**: React 18, Vite, Tailwind CSS, Lucide React Icons
- **Backend**: Express (Node.js/TypeScript)
- **Database / Storage**: Supabase (PostgreSQL + Object Storage) / In-Memory fallback

## Local Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

4. Start production server:
   ```bash
   npm start
   ```
